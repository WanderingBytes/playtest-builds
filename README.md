# Playtest Builds

Shareable web builds for in-development games. **Each game is its own subfolder** (e.g. `the-last-keep/`).

- Source code stays **private** (built from a private repo).
- Only the **exported playable web build** is published here.
- Hosted free via **GitHub Pages** (public repo = free unlimited Pages).
